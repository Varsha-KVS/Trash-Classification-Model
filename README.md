
# ♻️ Trash Classification Model

## 📌 About
A CNN-based Trash Classification Model built using Python and TensorFlow. It classifies waste images into 9 categories using deep learning to support efficient waste segregation.

## Waste Categories
- Cardboard
- Food Organics
- Glass
- Metal
- Miscellaneous Trash
- Paper
- Plastic
- Textile Trash
- Vegetation

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## 📊 Model Performance
- Test Accuracy: **60.36%**

## 🎯 Objective
To automate waste classification using deep learning and promote efficient waste management.
